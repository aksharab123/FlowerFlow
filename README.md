# 🌸 FlowerFlow

FlowerFlow is a Python-based computer vision project that uses MediaPipe
hand tracking to create an interactive floral visual experience.

## ✨ Features

- Real-time hand tracking
- Two-hand interaction
- Gesture-based visual effects
- Interactive flower animation
- Particle and sparkle effects

## 🛠️ Technologies

- Python
- MediaPipe
- OpenCV
- Computer Vision
